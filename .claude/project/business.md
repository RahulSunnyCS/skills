# Business & Product Context

claude-web-dev-skills is a free, MIT-licensed open-source developer tool. There
is no monetisation, no accounts, and no hosted service — it is distributed
purely as source consumed through `npx github:...`.

## Offering

- The full pipeline payload (15 agents, 12 commands, CLAUDE.md +
  `.claude/pipeline/` reference files) — free
- `init` / `sync` / `sync --check` CLI — free

## Tiers

None. No payment provider, no billing, no usage metering, no entitlements.

## Caveats

- **No billing surface → `pricing-reviewer` is N/A here.** It is already
  tag-gated (only runs when Triage sets the `pricing` tag); never set that tag
  for this repo.
- No compliance/legal billing constraints apply (nothing is charged or stored).
